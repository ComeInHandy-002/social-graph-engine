## 2. C++ 算法策略模式继承树

```
                        ┌─────────────────────┐
                        │   IGraphAlgorithm   │  抽象基接口
                        │   (Graph.h:55)      │
                        └──────────┬──────────┘
                                   │
           ┌───────────────────────┼─────────────────────────┐
           │                       │                         │
           ▼                       ▼                         ▼
┌─────────────────────┐ ┌─────────────────────┐ ┌─────────────────────┐
│IPathFindingAlgorithm│ │ IScoringAlgorithm   │ │ ICommunityAlgorithm  │
│execute(graph,start, │ │ execute(graph)      │ │ execute(graph)       │
│  target)→vector     │ │  →map<string,double>│ │  →map<string,string> │
└──────────┬──────────┘ └──────────┬──────────┘ └──────────┬──────────┘
           │                       │                         │
     ┌─────┼─────┐           ┌────┼────┬────┐          ┌────┼────┐
     │     │     │           │    │    │    │          │    │    │
     ▼     ▼     ▼           ▼    ▼    ▼    ▼          ▼    ▼
   BFS  Dijkstra DFS    PageRank KCore BC CC    LPA Connected
                         Betweenness                Components
                         ClusteringCoeff

各算法复杂度:
  BFS:              O(V+E)
  Dijkstra:         O((V+E)logV)
  DFS(回声室):       O(V+E)
  PageRank:         O(I·E), I=迭代次数
  Betweenness:      O(V·E) Brandes算法
  KCore:            O(V+E) Batagelj-Zaversnik
  ClusteringCoeff:  O(V·d_max²)
  LPA:              O(I·E)
  ConnectedComp:    O(V+E)
  GraphStats:       O(V+E)
```

## 3. 请求处理全链路 (追一条 PageRank 请求)

```
  浏览器 (前端)
     │
     │ GET /api/v1/graph/pagerank?max_iterations=5
     │ Authorization: Bearer <JWT>
     ▼
┌────────────────────────────────────────────────────────────────┐
│ 1. CORS 检查 (允许跨域)                                        │
│ 2. GZip 检测 (请求头 Accept-Encoding: gzip)                    │
│ 3. RateLimit (检查用户限流: 60/分钟)                            │
│ 4. RequestLog (记录: method, path, client_ip, request_id)     │
│ 5. JWT 验证 (提取用户角色: analyst)                             │
│ 6. 角色权限检查 (PageRank 需要 analyst 角色)                    │
└────────────────────────────────────────────────────────────────┘
     │
     ▼
┌────────────────────────────────────────────────────────────────┐
│ 7. CacheService: 查 Redis 缓存                                 │
│    键: sgp:graph:pagerank:v3                                  │
│    ├── 命中 → 直接返回 (跳过8-12)                               │
│    └── 未命中 ↓                                                │
│ 8. 获取分布式锁 (防缓存击穿)                                    │
│ 9. CppEngine: subprocess.run(graph_engine.exe pagerank)       │
│    → C++ 进程:                                                 │
│       a. 加载 facebook_combined.txt (88234条边)                 │
│       b. 初始化 PageRank 分数 (4039个节点)                      │
│       c. 迭代5轮, 每轮更新分数                                  │
│       d. JSON 输出到 stdout                                    │
│ 10. Python 解析 C++ JSON 结果                                  │
│ 11. 回写 Redis (版本 v3, TTL 24h, jitter ±10%)                 │
│ 12. 释放分布式锁                                               │
└────────────────────────────────────────────────────────────────┘
     │
     ▼
┌────────────────────────────────────────────────────────────────┐
│ 13. 响应: Content-Encoding: gzip                              │
│     {"status":"success","time_ms":352,"data":[...]}           │
└────────────────────────────────────────────────────────────────┘
     │
     ▼
  浏览器
     │
     ▼
  3D 渲染:
  - 节点大小 = PageRank 分数 × 15000
  - 颜色 = 社区标签
  - 标签显示 Top-10 节点 ID
```

## 8. 技术选型决策树

```
需要做什么?
  │
  ├─ 图算法计算 (CPU密集型)
  │   └─→ C++17 (性能最优, 零依赖)
  │
  ├─ API 网关 (I/O密集型)
  │   └─→ Python FastAPI (异步, 生态好)
  │
  ├─ 3D 可视化 (GPU渲染)
  │   └─→ WebGL + 3d-force-graph (浏览器原生)
  │
  ├─ 社交关系存储 (图遍历)
  │   └─→ Neo4j (原生图数据库)
  │
  ├─ 热数据缓存 (高频读)
  │   └─→ Redis (内存KV, 微秒级)
  │
  ├─ 用户数据 (事务)
  │   └─→ MySQL (ACID 保证)
  │
  ├─ 日志/时序数据
  │   └─→ MongoDB (文档灵活, 时序友好)
  │
  └─ 部署
      └─→ Docker Compose (6服务一键启动)
```
